# SecureOps 面试演示流程

本流程基于独立E2E环境验证，适合控制在5—10分钟内完成。演示只使用本人授权的测试环境和测试账号，不扫描外部目标。

## 1. 项目介绍（约1分钟）

SecureOps 是一个轻量级企业安全运营平台，将资产登记、授权扫描、漏洞管理、风险分析和安全报告串成一个可运行闭环。

重点说明：系统调用真实后端API和数据库，扫描目标必须经过授权。

## 2. 登录系统（约30秒）

打开系统登录页，使用专用演示账号登录。说明密码通过bcrypt哈希保存，登录后通过JWT访问受保护接口。

## 3. 查看安全态势Dashboard（约1分钟）

展示资产数量、漏洞数量、风险等级分布和高风险资产排行。强调数据来自风险统计API，不是前端静态数据。

## 4. 查看资产管理（约1分钟）

打开资产管理，展示资产名称、IP、主机名、类型和重要性。可演示资产详情抽屉和筛选功能。

## 5. 创建授权扫描（约2分钟）

进入扫描任务页面，创建目标为 `127.0.0.1` 的端口扫描任务，点击启动后等待Celery Worker执行。展示任务状态和扫描结果中的开放端口信息。

## 6. 查看漏洞（约1分钟）

进入漏洞管理，展示CVE编号、严重等级、CVSS和处理状态。说明漏洞记录与资产、扫描任务存在关联。

## 7. 查看风险分析（约1分钟）

返回Dashboard查看风险等级和高风险资产排行，说明风险分由漏洞严重度、CVSS、资产重要性和服务暴露情况组成。

## 8. 生成安全报告（约1分钟）

进入安全报告页面，生成报告并查看统计卡片，最后下载PDF文件。说明报告数据来自当前数据库快照。
