# 安全设计说明

密码使用 bcrypt 哈希保存，不保存明文。登录成功后签发配置化密钥的 JWT，受保护接口要求 `Authorization: Bearer <token>`。

管理员负责资产、漏洞、审计等管理操作；普通用户只能访问授权范围内的数据。

登录失败按用户名和来源 IP 计数，默认 5 次失败后限制 15 分钟；API 按 IP 默认限制 300 次/分钟。限流状态当前保存在进程内，多实例部署应使用 Redis 等共享存储。

应用日志不记录密码和 Token，重要操作写入审计表。Nmap 只接受格式校验后的目标和固定安全参数，不包含漏洞利用或攻击验证。自动化巡检只应配置组织已授权的资产；CVE 同步使用公开 NVD 数据，不将情报匹配结果直接当作已确认漏洞。

## 数据访问边界

普通用户只能读取自身创建或授权范围内的扫描、风险和报告数据；管理员负责资产、漏洞、审计和报告生成等管理操作。报告 HTML/PDF 接口沿用相同归属检查，避免通过文件导出绕过权限。
