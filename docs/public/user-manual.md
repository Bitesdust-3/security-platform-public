# 用户使用手册

## 1. 登录

打开 `http://localhost:8080`，使用部署时配置的演示账号或已注册账号登录。登录成功后前端保存 JWT，并自动为 API 请求添加 Bearer Token。

## 2. 资产管理

进入“资产管理”，管理员可以新增、编辑和停用资产；所有用户可以在授权范围内查看资产列表和详情。资产应填写真实的授权 IP、主机名、类型和重要性。

## 3. 扫描与自动化巡检

在“扫描任务”创建基础端口扫描，填写已授权目标后提交并启动任务。在“自动化巡检”中可配置一次性、每日、每周或 Cron 计划。Worker 执行后，结果会保存为扫描记录并同步发现的服务。

## 4. 漏洞和 CVE 情报

“漏洞管理”用于维护业务漏洞状态、CVSS 和整改建议；“CVE 情报”用于查看 NVD 同步数据。CVE 情报是参考信息，未经验证不得直接视为目标资产已确认漏洞。

## 5. 风险和报告

“风险总览”展示风险等级、趋势和高风险资产。管理员可在“安全报告”生成统计周期报告，并查看 HTML 或下载 PDF。报告统计来自当前数据库快照。

## 6. 审计日志

管理员进入“审计日志”查看登录、资产、扫描和漏洞操作记录。普通用户无权访问管理员审计查询接口。

## 安全边界

只对明确授权的实验资产执行扫描，不填写公网未知目标，不尝试漏洞利用或攻击验证。
