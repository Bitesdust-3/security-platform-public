# 简历和面试项目说明

## 一句话介绍

基于 FastAPI、Vue 3 和 MySQL 开发的轻量级企业安全运营平台，实现资产管理、授权 Nmap 发现、漏洞生命周期管理和可解释风险分析。

## 技术亮点

- 使用 Argon2id 和 JWT 实现认证。
- 使用 SQLAlchemy 建模资产、扫描任务和漏洞关联。
- 通过参数化 Nmap 调用和目标白名单控制扫描风险。
- 通过资产重要性、漏洞严重性和开放服务计算风险分数。
- 使用 Docker Compose 编排前端、后端和 MySQL。

## 面试重点

重点说明安全边界、数据模型、扫描命令注入防护、风险评分可解释性和项目当前限制。
