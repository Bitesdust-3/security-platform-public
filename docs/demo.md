# 面试演示脚本

## 演示前准备

```bash
cp .env.example .env
# 设置数据库密码、Root密码、JWT_SECRET_KEY 和演示管理员密码
docker compose -f docker/docker-compose.yml --env-file .env up --build -d
```

访问 `http://localhost:8080`，使用 `.env` 中的演示管理员账号登录。

## 推荐演示流程

1. 登录系统，展示 SecureOps 登录页和 JWT 认证。
2. 进入风险总览，介绍资产数量、漏洞数量、风险等级和趋势图。
3. 进入资产管理，新增一个 `127.0.0.1` 授权实验资产，展示详情和重要性。
4. 进入扫描任务，创建端口扫描并启动，展示 pending、running、completed 状态。
5. 打开扫描结果，说明 Nmap XML 解析和服务信息同步到资产。
6. 进入漏洞管理，查看 CVE、CVSS、严重等级和处置状态。
7. 进入自动化巡检，创建每日或 Cron 计划，说明 Beat 投递、Worker 执行过程。
8. 进入 CVE 情报，展示 NVD 数据是独立情报表，不等同于已确认漏洞。
9. 返回风险分析，展示高风险资产排行和可解释风险评分。
10. 进入安全报告，生成统计周期报告，打开 HTML 或下载 PDF。
11. 进入审计日志，展示关键操作可追溯。

## 演示注意事项

- 只扫描本机或明确授权的实验资产。
- 不在演示中输入公网未知目标。
- 演示账号和密码仅用于本地环境，公开部署前必须更换。
- 若没有 Nmap，扫描会安全失败，但其他模块仍可演示。
